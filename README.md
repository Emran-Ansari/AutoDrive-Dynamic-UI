
# AutoDrive-Dynamic-UI
A single-page car showroom web project for AutoDrive. Built with HTML, CSS, and Pure JavaScript to show smooth navigation and car filtering.

# properties:
    1. Project pages (Home, Inventory, About, Contact, etc.) are designed in a way that users can navigate between them smoothly without reloading the page.
    2. Includes a dynamic filtering system where users can search and filter cars by brand instantly.
    3. Features smart JavaScript alerts that guide users to sign up or log in before placing an order.

# Future Plans: 
    1. Migrating to React: Converting the entire layout into React components for better state management and cleaner code.
    2. Adding a real database: Connecting login forms to a backend system to allow users to save their real car orders.
